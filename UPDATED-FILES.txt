WHAT CHANGED
============
1. Amazon Country section (Amazon stores only): the daily entry form now asks for a Country
   (US / CA / MX / AU / UK / DE / IT / JP / FR / ES / IN / AE) when the selected store is an
   Amazon store, and the Report tab gains a "🌍 Amazon — Country-wise Budget / Spend" table.
   Etsy / eBay / Website stores are untouched — one row per day, as before.
2. Statement verification + link: every Report row (Monthly Roll-up, Daily Master, Amazon
   Country) now shows whether that store's orders were actually found in the store's imported
   marketplace statement (✅ / ⚠️ / ⏳) and links straight to that store's statement detail for
   the month (/dashboard/reports/store-expenses?store=…&from=…&to=…).
3. B2B PI: pehle chup-chaap "To be provided" chhap raha tha jab PI ki migration run nahi hui thi.
   Ab ek explicit-column probe query fail hoti hai, aur wahi message 🛠️ setup card par pahunchta
   hai jo chalane wali SQL files ki list dikhata hai (ab us list me
   db/2026-10-13-b2b-pi-export-fields.sql bhi hai). Register/quotations/payments pehle jaise
   load hote rahenge — sirf missing-column wala hissa screen par aa jayega.
