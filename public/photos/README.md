# Homepage artwork (optional)

The NYKO INFOTEC 3D homepage (`/index.html`) works fully without any files here —
it renders a pure CSS/SVG 3D scene. Drop your rendered images into this folder with
these exact names and they light up automatically:

| File | Where it appears |
| --- | --- |
| `hero.jpg` | Soft backdrop behind the hero 3D scene (auto-dimmed, ~55% opacity) |
| `scene-ecommerce.jpg` | "Built by NYKO INFOTEC" gallery card — E-commerce solutions |
| `scene-cloud.jpg` | Gallery card — Cloud & infrastructure |
| `scene-global.jpg` | Gallery card — Global reach |
| `scene-support.jpg` | Gallery card — Customer support |
| `scene-security.jpg` | Gallery card — Data security |

Notes:

- JPG or PNG both work; keep each under ~400 KB for fast loading.
- Gallery cards are portrait-ish (3:4) — 1200×1600 or similar crops best.
- If a file is missing, that card hides itself; if none are present the whole
  gallery section stays hidden. No broken image icons, ever.
